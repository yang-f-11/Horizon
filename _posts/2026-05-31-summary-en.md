Technically, the algorithm is a 2.5D height map raycasting method, not true volumetric voxel rendering, and renders terrain by projecting columns of pixels from a height and color map.

**Background**: Voxel Space is a terrain rendering technique used in the 1992 game Comanche that eschews triangles in favor of a height map and color map. It was efficient on 1990s hardware and considered a 2.5D engine because it lacks full 3D freedom. Height maps store elevation data in a raster image, while this algorithm renders columns of pixels along scanlines.

## [Researchers Disclose FROST Attack Using SSD Timing](https://futurism.com/future-society/websites-spying-solid-state-drive) ⭐️ 8.0/10

Researchers have disclosed the FROST attack, a novel side-channel method that exploits browser OPFS and SSD read/write timing to infer a user's concurrent website visits or application usage with up to 88.95% accuracy for websites and 95.83% for applications, without requiring any software installation or user interaction. This attack runs entirely in the browser and does not require any user interaction, posing a significant privacy threat by allowing malicious websites to spy on concurrent user activities. It highlights a new class of side-channel vulnerabilities that may prompt browser vendors and OS developers to reconsider security measures. The FROST attack was tested only on macOS and Linux, but the researchers believe Windows is not immune. Users can reduce risk by closing unused browser tabs. The attack leverages the browser's Origin Private File System (OPFS) and SSD timing as a side channel to infer activities.

telegram · zaihuapd · May 31, 01:55

**Background**: The Origin Private File System (OPFS) is a browser-provided sandboxed file system private to each website's origin, enabling fast file operations. A side-channel attack monitors indirect signals such as timing variations to infer sensitive information without directly accessing it. SSD timing attacks measure how long read/write operations take to detect concurrent system activity. The FROST attack combines both by using OPFS file operations to create SSD activity and timing the responses to infer what other applications or websites the user is accessing.

Samsung is reportedly researching a fanless liquid cooling system for future Galaxy smartphones to handle the heat generated by generative AI, real-time translation, image generation, and large model processing. If commercialized, liquid cooling could enable more sustained AI performance in smartphones without throttling, setting a new standard for thermal management in mobile devices. Samsung has set up a dedicated team under its Production Engineering Research Institute to advance liquid cooling research, but commercial use may still be years away due to challenges such as waterproofing, durability, manufacturing cost, and internal space constraints.
