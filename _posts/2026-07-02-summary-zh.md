## [首个从零构建的合成细胞成功生长分裂](https://www.quantamagazine.org/for-the-first-time-a-cell-built-from-scratch-grows-and-divides-20260701/) ⭐️ 10.0/10

明尼苏达大学 Kate Adamala 领导的团队创造了 SpudCell，这是首个完全由非生命化学成分构建并能够生长、复制基因组和分裂的合成细胞。该成果于 2026 年 7 月在线发表。 这一突破证明最小化合成细胞能够展示完整生命周期，使合成生物学更接近实际应用，如药物制造、环境监测以及理解生命起源。 SpudCell 绕开了天然细胞骨架的复杂性，采用简单的物理分裂机制：通过融合脂肪酸液滴生长，分裂由渗透压自发驱动。细胞的基因组包含用于复制、转录和翻译的合成基因，但核糖体生产外包给了外部提取物。

hackernews · defrost · Jul 1, 14:20 · [社区讨论](https://news.ycombinator.com/item?id=48747304)

**背景**: 合成生物学旨在从零构建活细胞以理解生命原理并创造有用的生物技术。此前的研究已实现合成基因组和细胞生长，但细胞分裂一直是一大难题，因为天然分裂依赖于复杂的细胞骨架。SpudCell 通过设计更简单的分裂机制克服了这一障碍，标志着合成细胞首次完成完整的生长分裂周期。

## [Cloudflare 推出 x402 货币化网关](https://blog.cloudflare.com/monetization-gateway/) ⭐️ 8.0/10

Cloudflare 宣布推出一个货币化网关，允许通过 HTTP 402 状态码对其网络背后的任何资源收费，从而为机器人和 AI 代理启用微交易。与 Coinbase 共同创立的 x402 协议为基于 HTTP 的支付提供了标准。 这可能会彻底改变网站对机器人流量的货币化方式，无需传统支付轨道即可实现微交易。它解决了自动化代理付费访问的需求，可能减少 API 密钥管理，并为网络带来新的经济模式。 x402 标准使用 HTTP 402 响应包含支付指令；客户端必须先付费才能访问资源。Cloudflare Workers 和 AI Agents 原生支持 x402，x402 基金会旨在鼓励采用。

hackernews · soheilpro · Jul 1, 13:59 · [社区讨论](https://news.ycombinator.com/item?id=48746914)

**背景**: HTTP 402 状态码“需要付款”是保留供将来使用的状态码，尚未广泛实施。x402 是一个围绕该代码构建的新支付标准，允许服务返回包含支付详情的 402 响应。Cloudflare 的规模可能推动此前微支付尝试未能实现的采用。
