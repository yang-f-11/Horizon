## [Anthropic replaces Git with custom Scion source control](https://simonwillison.net/2026/Oct/13/redesigning-source-control-at-anthropic/) ⭐️ 9.0/10

Anthropic published an engineering post explaining why and how it built Scion, its own centralized source control system, and migrated its main monorepo off Git in five months using a team of just seven engineers. The move was driven by a surge in merged code changes from roughly 2,500 per day in May 2026 to over 30,000 per day by September, peaking at 30,401 on September 9. Git is the default version control layer for almost all software teams, so a leading AI lab concluding that it no longer scales for AI-driven development velocity is a significant signal for the broader developer-tools ecosystem. If agent-generated code keeps multiplying merge volume, other large monorepo operators may face similar pressure to rethink their source control and code review infrastructure. Anthropic says the main branch history alone is almost 100 GB with a compressed working copy over 25 GB, and that it performs roughly 25 million code checkouts per day for CI, which would amount to over 600 PB of Git traffic daily if fetched naively. Scion keeps clients always online and does computation server-side with distributed storage, reportedly using about 1/200 of the CPU and memory of the previous Git mirror architecture, speeding CI checkouts roughly 100x and cutting CI compute by 25%; an engineer also confirmed there is no offline support because Claude is the heaviest user and is necessarily online.

rss · Simon Willison · Oct 13, 23:00

**Background**: A monorepo is a single repository holding the code for many projects and services, which simplifies dependency management and cross-team changes but becomes painful as history and file counts grow — large Git repositories commonly need workarounds such as sparse checkout, partial clone and shallow fetch to stay usable. Git is a distributed version control system where each developer holds a full copy of the repository history, whereas earlier centralized systems like Subversion relied on a server that clients contact for most operations; Scion appears closer to that centralized model. Anthropic's change-rate spike coincides with heavy internal use of its Claude models for coding, plus a new review system called Antique and a practice of adversarial review where one model critiques another model's work.

## [Guitoro: A Free Browser Guitar You Strum With Your Keyboard](https://guitoro.com/) ⭐️ 7.0/10

Guitoro launched on Hacker News as a free, browser-based virtual guitar built from recordings of real instruments, playable with a keyboard, mouse, or touchscreen. It offers acoustic, classical, and electric guitar plus bass, displays chord fingerings and each stroke, and includes song practice that can be slowed to 20%, along with free chord tools and tuners and no signup or download. It demonstrates how far the Web Audio API has come: a polished, zero-install musical instrument that runs entirely in the browser, which lowers the barrier for casual learners and music educators. The launch also surfaced a broader idea — that a standard keyboard is already a playable instrument for anyone who can type — pointing to new directions for interactive music and practice tools. The practice mode's ability to slow songs to 20% depends on time-stretching so the tempo drops without the pitch changing, which is a non-trivial DSP requirement for a browser app. The creator explicitly asks for feedback on how the strumming feels and sounds, and provides a one-minute video demo; note that this is an engaging web app rather than a technical breakthrough.

hackernews · talccc · Oct 13, 19:11 · [Discussion](https://news.ycombinator.com/item?id=50077020)

**Background**: Guitoro is built on the Web Audio API, a high-level JavaScript interface that lets web applications generate, process, and route audio directly in the browser without plugins. Its realistic instrument sounds come from sample-based synthesis, in which short recordings of real instruments are used as the raw material instead of synthesized waveforms, which is why acoustic guitar and bass can sound convincing. Slowing playback while keeping pitch constant is achieved through audio time-stretching, a technique that changes duration independently of pitch and is commonly used to adapt or practice recorded material.

## [Mozilla Launches Firefox Enterprise to Win Business Deployments](https://www.firefox.com/en-US/enterprise/) ⭐️ 7.0/10

Mozilla has launched Firefox Enterprise, a dedicated offering that provides enterprise-grade management controls, deployment tooling and support so that organizations can standardize on Firefox instead of Chrome or Edge. The announcement is framed explicitly as a bid to compete for business deployments, a segment where Firefox has long been absent from corporate fleets. Enterprise deployment decisions lock in browser market share for years, so gaining IT approval is one of the few levers that could reverse Firefox's long decline in usage share. It also puts Mozilla into a fast-growing enterprise browser security market, where vendors such as Island have raised hundreds of millions of dollars and where Google, Microsoft and several startups already compete. Firefox has historically lacked the centralized administrative controls that Chrome and Edge expose through Group Policy, configuration profiles and cloud admin consoles, which is why many corporate policies simply block its installation. Mozilla enters this race far behind incumbents, and commenters note the main driver of enterprise browser spending today is data-loss prevention, including stopping employees from pasting sensitive data into AI chat apps.

hackernews · recvonline · Oct 13, 12:00 · [Discussion](https://news.ycombinator.com/item?id=50070302)

**Background**: In corporate IT, browsers are usually managed centrally: administrators push settings through Windows Group Policy or mobile device management profiles, control extensions and updates, and enforce security rules without touching each user's machine. A browser that cannot be managed this way is typically banned outright, because IT cannot guarantee compliance or security. 'Enterprise browsers' are a newer category that adds features such as data-loss prevention, per-app VPN-less access to internal intranets and granular audit logging on top of standard browsing. Firefox's historical absence from this tooling is a major reason it lost ground on corporate desktops.

**Discussion**: Sentiment is mixed but broadly hopeful: solatic argues the enterprise market is huge — pointing to Island's $400M Series F at a $6.4B valuation — while warning Mozilla is very far behind, and nicoburns and PaulHoule call the move necessary and one of Firefox's most practical strategic ideas in years. ## [Pre-commit hooks can steer coding agents by injecting corrective prompts](https://simonwillison.net/2026/Oct/13/geoffrey-huntley/) ⭐️ 7.0/10

Geoffrey Huntley describes a technique in which a pre-commit hook inspects the git diff for direct calls to observability modules that bypass his diagnostics library, fails the commit when it finds them, and injects a prompt telling the coding agent to use the diagnostics library instead. He reports that this instantly turned the agent's behavior into a "ten out of ten". It shows a shift from soft, document-based guidance (like AGENTS.md) toward hard, deterministic guardrails enforced at the git layer, where the failure message itself becomes the correction signal fed back to the agent. As coding agents become mainstream, such mechanical enforcement loops are likely to matter more than purely prompt-based instruction for keeping large codebases architecturally consistent. The mechanism relies on the standard git hook contract: a pre-commit hook runs before the commit is finalized, and exiting non-zero aborts it, with the hook's output available for the agent to read — though developers can still bypass it with `git commit --no-verify`. Huntley's stated reason for preferring this over editing AGENTS.md is that static instructions have "a delta" and drift over time, and the news item itself is only a short quote without extended analysis.

rss · Simon Willison · Oct 13, 13:32

**Background**: Coding agents are AI systems that read and modify a repository on a developer's behalf, and AGENTS.md has become a widely used open convention — essentially a README for agents — that gives them project-specific instructions and context. Git hooks are scripts Git executes around events such as commit and push; the pre-commit hook in particular inspects the snapshot about to be committed and aborts the commit if the script exits with a non-zero status. Because agents typically run git commands themselves and consume command output, a failing hook doubles as an automated, timely instruction channel rather than just a gate.

## [Judge Orders Google to Strip Friction From Rival Android App Store Installs](https://t.me/zaihuapd/44392) ⭐️ 7.0/10

US District Judge James Donato ordered Google to simplify the installation of competing Android app stores, requiring it to remove the extra steps and warning pop-ups in the Play Store flow that currently appear before an install can proceed. Google has one week to make the change so that installing a third-party marketplace is as direct as installing any ordinary Android app. This is the first concrete remedy to emerge from the Epic v. Google antitrust verdict, and it directly targets the user-interface friction that rival stores like the Epic Games Store have blamed for their inability to reach mainstream Android users. If it holds, it could meaningfully loosen Google's grip on Android app distribution and shift leverage toward developers and alternative marketplaces. The court characterized multi-step sequences — such as an extra "review" screen that only afterwards leads to an "install" button — as deliberately engineered "anticompetitive friction" designed to scare off ordinary users rather than to protect them. The order therefore requires parity: a third-party store install must take no more steps than a normal Android app install.

telegram · zaihuapd · Oct 13, 23:17

**Background**: Epic Games sued Google in 2020 over Play Store policies, and a jury later found that Google had illegally monopolized Android app distribution, leaving Judge Donato to fashion remedies. The disputed flow concerns sideloading — manually installing apps as APK files outside the Play Store — which Google has long wrapped in security warnings and multi-step confirmations it says protect users from malware. This ruling treats those warnings, at least for competing app stores, as a competitive barrier rather than a safety feature.

## [GitHub Bans KernelSU Lead Developer and Several Related Open-Source Organizations](https://x.com/realnullptr/status/2110025105338519970) ⭐️ 7.0/10

Developer RealNullptr (account Dr-TSNG) says GitHub banned his personal account and several organizations he co-owns — KernelSU-Module-Repo, Kernel-SU and libxposed — roughly a month ago, taking key KernelSU community infrastructure offline. GitHub has issued no public explanation for the ban, and the developer speculates it may be linked to Student Developer Pack eligibility review. KernelSU is a widely used Android rooting solution and a major alternative to Magisk, so removing its lead developer's account and core organizations disrupts module distribution, code hosting and community support for a large user base. The unexplained nature of the action also raises broader platform-governance and dependency-risk questions about how much of the open-source ecosystem relies on a single commercial host that can remove projects without public justification. The ban reportedly affects the accounts Dr-TSNG, KernelSU-Module-Repo, Kernel-SU and libxposed, and has already been in place for about a month without any public statement from GitHub. The only explanation offered comes from the developer himself, who guesses the Student Developer Pack verification process may be involved, meaning the actual cause remains unconfirmed.

**Background**: KernelSU is a kernel-space root solution for Android that integrates superuser (su) access management directly into the Linux kernel, letting users grant root privileges without the systemless patching approach used by Magisk; it is developed as free and open-source software under the GPLv3 license. The GitHub Student Developer Pack, launched in 2014, gives verified students free or discounted access to developer tools, cloud credits and partner offers, so Student Pack abuse is a common reason GitHub applies account restrictions. Because KernelSU's modules, documentation and issue trackers live largely in GitHub organizations, a ban at the organization level can disable far more than a single person's login.
