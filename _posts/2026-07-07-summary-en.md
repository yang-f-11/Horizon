## [Anthropic Discovers Global Workspace in Language Models](https://www.anthropic.com/research/global-workspace) ⭐️ 9.0/10

Anthropic's research identifies a shared reasoning subspace in large language models, termed a 'global workspace,' which functions as a central coordinating hub for information processing. This discovery provides a new framework for understanding how LLMs integrate and coordinate information, potentially leading to more interpretable and controllable AI systems. The global workspace was identified through experiments inspired by global workspace theory in neuroscience, and the paper includes commentary from Neel Nanda of Google DeepMind, who performed a small-scale replication on an open-weight model.

hackernews · in-silico · Jul 6, 17:44 · [Discussion](https://news.ycombinator.com/item?id=48808002)

**Background**: Global workspace theory (GWT), proposed by Bernard Baars in 1988, is a cognitive architecture that explains conscious access by positing a central workspace that broadcasts information to various cognitive modules. Anthropic's research suggests that LLMs, like Claude, may have developed a similar workspace to serve a functional role analogous to conscious access, though this does not imply consciousness in machines.

These features address long-standing feature requests and make sqlite-utils more robust for complex database schemas. The release candidate status indicates the stable 4.0 release is imminent, providing significant improvements to a widely-used Python utility for SQLite. The compound foreign key support required a subtle breaking change to the table.foreign_keys attribute, which is why it needed to land in a major version. The case-insensitive column matching change touched many parts of the codebase.

rss · Simon Willison · Jul 6, 05:40

**Background**: sqlite-utils is a Python library and command-line tool for working with SQLite databases, offering utilities for creating, querying, and transforming tables. Compound foreign keys allow a foreign key to reference multiple columns (a composite key), which is a SQLite feature that was previously unsupported in sqlite-utils. Case-insensitive column matching means column names are treated case-insensitively, aligning with SQLite's default behavior when using certain collations or pragmas.

## [Claude Cowork Sandbox Escape Vulnerability Discovered](https://cyberpress.org/claude-cowork-flaw/) ⭐️ 7.0/10

A sandbox escape vulnerability in Anthropic's Claude Cowork feature allows attackers with local code execution to break out of the bubblewrap sandbox and exfiltrate sensitive files like /etc/shadow. This vulnerability undermines the security isolation promised by Claude's sandbox, potentially exposing user credentials and system configuration. However, the requirement for prior local code execution significantly limits the attack's practical impact. The attack chain uses DLL sideloading on claude.exe and two unvalidated parameters (isResume and allowedDomains) in the spawn interface to gain root in the Ubuntu VM and use nsenter to escape the bubblewrap sandbox. Anthropic classified the issue as 'not a security concern' because it requires the host to already be running malicious code.

**Background**: Bubblewrap is a lightweight sandboxing utility that uses Linux namespaces to restrict an application's access to the system. nsenter is a command-line tool that allows entering another process's namespaces, which can be used to escape a sandbox if privileged access is obtained. DLL sideloading is a technique where a malicious DLL is placed in a location where a legitimate application loads it, allowing code execution.

## [Android backup policy change: SMS, call logs now count toward storage](https://9to5google.com/2026/07/06/android-backup-data-update/) ⭐️ 7.0/10

Starting July 7, Google will count SMS messages, call logs, and device settings in Android backups toward the free 15GB Google Account storage quota. This policy change affects all Android backup users and may encourage some to purchase additional storage, though the average increase is only about 40 MB per backup. Previously, only photos, videos, and MMS messages counted toward storage; the new rule adds text messages, call logs, and device settings as of July 7.

**Background**: Android backups include app data, call history, device settings, SMS, and photos/videos. Google offers 15GB of free storage per account, shared across Drive, Gmail, and Google Photos. The new policy aligns backup data types with storage quota rules, closing the previous exemption for SMS and call logs.
