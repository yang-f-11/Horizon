EVE Online announced the start of its migration from Stackless Python 2.7 to Python 3, using the futurize script on 2.4 million lines of code. The team will then manually review approximately 20,000 places where Python 2 and 3 behaviors differ. This marks a major milestone for the Python community, as EVE Online is one of the largest and longest-running Python codebases in production. rss · Simon Willison · Aug 25, 22:59

**Background**: Stackless Python is an enhanced version of the Python interpreter that adds microthreads, called tasklets, and communication channels, allowing hundreds of thousands of tiny tasks to run in a single thread. EVE Online has relied on Stackless Python since its launch in 2003, last upgrading to Stackless Python 2.7 in 2010. Python 2 reached end-of-life in 2020, but migrating a codebase this large with deep Stackless dependencies is a complex, multi-year effort.
