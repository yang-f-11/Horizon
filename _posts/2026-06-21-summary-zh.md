## [HTTP 拟新增 QUERY 方法：支持请求体的安全查询](https://httpwg.org/http-extensions/draft-ietf-httpbis-safe-method-w-body.html) ⭐️ 8.0/10

IETF HTTP 工作组提出了一种新的 HTTP QUERY 方法，该方法允许客户端发送带有请求体的安全且幂等的查询，解决了 GET 请求中 URI 长度限制的问题，并支持缓存。 这一提案可能显著改善 Web API 设计，通过提供标准化的方式执行复杂查询，而不会超出 URI 长度限制或影响可缓存性，有利于构建 RESTful 服务和 GraphQL API 的开发者。 该草案定义了一个新的 'Accept-Query' 响应头，用于服务器声明支持的查询格式，并且该方法被设计为安全和幂等的，允许自动重试。该草案将于 2026 年 12 月到期，目前仍在积极讨论中。

telegram · zaihuapd · Jun 20, 06:28

**背景**: 传统的 HTTP 方法存在局限：GET 是安全和幂等的，但有 URI 长度限制；POST 可以有请求体，但不是安全或幂等的，使得缓存和重试变得复杂。QUERY 方法通过结合两者的优势弥补了这一缺口。这是 HTTP 协议持续演进的一部分，以更好地支持现代 Web 应用。
