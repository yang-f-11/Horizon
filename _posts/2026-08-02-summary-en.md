Connes' rigidity conjecture is a central conjecture in operator algebras about when von Neumann algebras determine the structure of underlying groups, and a counterexample would overturn a widely believed principle.

An article on openrss.org analyzes how Google's decisions, above all the 2013 shutdown of Google Reader, significantly contributed to the decline of RSS adoption on the web. The article also points to related losses such as Mozilla's removal of RSS Live Bookmarks in Firefox 64, while noting that RSS remains widely used.

**Background**: RSS (Really Simple Syndication) is an XML-based web feed format that lets users subscribe to website updates through news aggregators, which can run in browsers, on desktops, or on mobile devices. It gained widespread adoption between 2005 and 2006 and became a standard way to follow blogs, news sites, and podcasts. Google Reader was one of the most popular RSS aggregators, and its closure is widely seen as a turning point that pushed ordinary users away from RSS.

## [Ripgrep musl Binaries Segfault on Very Large Searches](https://github.com/BurntSushi/ripgrep/issues/3494) ⭐️ 7.0/10

A bug report on the ripgrep GitHub repository shows that musl-linked binaries occasionally segfault during very large searches. The issue has sparked a technical discussion about allocator inefficiency and kernel behavior. This issue affects developers who rely on ripgrep for fast search, especially in static musl builds. It highlights broader systems-level concerns about allocator performance, multithreading, and kernel interactions, which can impact performance and stability across many tools. The segfault appears to be related to how the default musl allocator (mallocng) handles contention and memory-mapped I/O during large serial searches. A separate analysis repository by dfoxfranke provides a deep dive, and a kernel patch link was shared in the discussion. The problem may be specific to musl because of its allocator design and interaction with the kernel.

hackernews · throwaway2037 · Aug 1, 12:34 · [Discussion](https://news.ycombinator.com/item?id=49133889)

**Background**: musl is a lightweight, efficient, and standards-conformant C standard library for Linux, often used for static linking. Its default memory allocator, mallocng, introduced in musl 1.2.1, aims for strong hardening but has known performance issues under multithreaded contention. Ripgrep is a popular fast search tool; users building it with musl can encounter rare crashes during very large searches, which points to subtle interactions between the allocator, memory-mapped files, and the Linux kernel.

The NetBSD project released NetBSD 11.0, a major version of the operating system. This release includes improvements to the NPF firewall, including layer 2 and user/group filtering, and a new MICROVM kernel for x86 that can boot in about 10 ms. This is a notable milestone for one of the oldest open-source Unix-like operating systems, giving users better firewall capabilities and a new low-latency boot path. The NPF firewall changes add layer-2 filtering and rules based on user and group IDs, useful for per-user traffic control. The MICROVM kernel targets QEMU's 'microvm' machine and is designed for fast boot and small memory footprints, with a sample configuration available in the NetBSD source tree.

NPF is NetBSD's BSD-licensed stateful packet filter, comparable to tools like PF, ipfw, or iptables. The new MICROVM kernel is an experimental configuration that, combined with QEMU's microvm machine type, can boot in roughly 10 milliseconds, which is useful for short-lived virtual machines and micro-services.
