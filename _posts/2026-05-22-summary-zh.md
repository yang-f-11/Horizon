## [Freenet 重新设计：基于 WebAssembly 合约的去中心化应用](https://freenet.org/) ⭐️ 8.0/10

新的 Freenet 是从零开始重新设计的点对点平台，使用 WebAssembly 合约定义全局去中心化键值存储，已有去中心化群聊 River 和 CMS Delta 等应用在运行。 此次重新设计重新激活了一个历史悠久的 P2P 项目，采用将键视为可执行合约的新型架构，有望在无区块链开销的情况下实现灵活的去中心化应用。其独特的可交换合并方法实现了快速状态同步，可能降低构建 P2P 应用的门槛。 每个合约包含一个必须可交换的合并操作，使得状态更新像病毒一样传播，并在几秒内达成一致。应用以单页 Web 应用形式运行，通过 WebSocket 连接本地 Freenet 节点。

hackernews · sanity · May 21, 14:34 · [社区讨论](https://news.ycombinator.com/item?id=48223362)

**背景**: Freenet 最初创建于 2000 年代初，是一个匿名点对点文件共享网络，后来更名为 Hyphanet。重新设计的 Freenet 使用 WebAssembly（WASM）——一种在浏览器中高效运行的低级二进制格式——来定义类似智能合约的数据存储和变更逻辑。可交换合并方法类似于冲突无关复制数据类型（CRDTs），允许多个节点并发更新数据而不产生冲突。

## [新闻机构限制互联网档案馆访问，威胁数字保存](https://www.niemanlab.org/2026/05/more-than-340-local-news-outlets-are-limiting-the-internet-archives-access-to-their-journalism/) ⭐️ 8.0/10

超过 340 家地方新闻机构正在限制互联网档案馆（Internet Archive）对其新闻报道的存档，通常通过更新其 robots.txt 文件来阻止 Wayback Machine 的爬虫。 这一趋势威胁到地方新闻的长期保存，而这对历史研究、事实核查和问责制至关重要。如果没有存档副本，未来几代人可能会失去获取那些悄然消失或被修改的重要报道的途径。 这些限制通常通过 robots.txt 文件实施，专门阻止互联网档案馆的爬虫。一些机构完全禁止存档，另一些允许在延迟（例如一周）后访问，但许多并不这样做。截至 2025 年，互联网档案馆的 Wayback Machine 已存档超过 1 万亿个网页。

## [DeepSeek API 更新限速与 user_id 隔离功能](https://api-docs.deepseek.com/zh-cn/quick_start/rate_limit) ⭐️ 7.0/10

DeepSeek API 发布了更新后的限速文档，明确了 deepseek-v4-pro 模型的并发限制为 500，deepseek-v4-flash 为 2500，并引入了新的 user_id 参数，以实现包括内容安全、KVCache 和调度隔离在内的更细粒度并发管理。 这一更新直接影响到大规模使用 DeepSeek API 的开发者和企业，使他们能够更好地管理并发，并为每个用户实施隔离策略，同时提供明确的限制以避免意外的限流。 对于普通 API 用户，所有 user_id 合并计算并发；对于已提升配额的账号，每个 user_id 除了受账号总并发限制外，还有自己的单用户并发限制。超出限制会返回 HTTP 429 错误，用户可免费申请扩容。

telegram · zaihuapd · May 21, 15:03

**背景**: 限速是一种常见的 API 实践，限制用户或系统在给定时间内可发出的请求数量，以确保公平使用和稳定性。KVCache 是 Transformer 推理中的一种优化技术，用于存储注意力层的中间状态以避免重复计算。user_id 隔离功能允许 API 消费者在同一个 API 密钥下对不同终端用户的流量进行分段，从而实现对每个用户的安全和性能控制。
