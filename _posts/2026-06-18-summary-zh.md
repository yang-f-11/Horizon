## [RFC 10008 提出新的 HTTP QUERY 方法，用于带请求体的安全查询](https://www.rfc-editor.org/info/rfc10008/) ⭐️ 8.0/10

RFC 10008 于 2025 年 5 月 27 日发布，定义了一种新的 HTTP QUERY 方法，它是安全且幂等的，允许请求体携带查询参数，解决了 GET 不能有请求体而 POST 不幂等的局限性。 这是多年来首个新的 HTTP 方法，对 Web API、缓存和 HTML 表单有重大影响——支持可缓存、幂等的查询，可携带复杂载荷，且没有 POST 的副作用风险。 QUERY 方法安全且幂等，意味着没有显著的副作用，且多次相同请求产生相同结果。QUERY 的缓存策略可能包括按位比较请求体。

hackernews · schappim · Jun 17, 10:51 · [社区讨论](https://news.ycombinator.com/item?id=48568502)

**背景**: HTTP 定义了 GET（无请求体）和 POST（不幂等）等方法。开发者有时需要发送请求体进行查询，导致使用 POST 或发送带体的 GET 等变通方法，引发了互操作性问题。IETF 工作组决定创建新的 QUERY 方法来标准化这一模式。

**社区讨论**: Hacker News 上的评论者讨论了缓存的复杂性，指出将请求体包含在缓存键中很不寻常，可能导致无限的键。有人称赞 HTML 表单可能使用 method='query' 以避免重新提交警告。有评论者提到多年来一直在 GET 中发送请求体，但 IETF 拒绝了这个选项。
