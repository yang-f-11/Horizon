## [Science Reveals Girl's Death in Unregulated Gene Editing Trial at Chinese Hospital](https://t.me/zaihuapd/42777) ⭐️ 10.0/10

Science magazine published an exclusive investigation on July 23, 2026, revealing that a 6-year-old girl died in March 2025 after receiving an experimental base editing gene therapy at Xinhua Hospital in Shanghai, with the incident covered up and never publicly disclosed. This is a landmark case of a patient death in an unmonitored gene therapy trial, raising urgent questions about regulatory oversight of gene editing in China and globally, and potentially reshaping international standards for clinical trials. The girl had a rare monogenic disease caused by a single base mutation; the team injected trillions of adeno-associated virus (AAV) vectors via spinal fluid to target brain neurons, and she died from a severe immune reaction 7 days later. Her parents paid over $800,000 out-of-pocket, and the ClinicalTrials.gov record had not been updated for over a year.

AAV vectors are commonly used to deliver therapeutic genes, but high doses can trigger immune responses. Intrathecal injection delivers treatment directly into the cerebrospinal fluid to reach the central nervous system. The regulatory framework for gene therapy trials in China requires ethical approval and oversight, but this trial appears to have bypassed standard procedures.

## [Decker: A modern revival of HyperCard for interactive documents](https://beyondloom.com/decker/) ⭐️ 8.0/10

Decker is a modern reimplementation of HyperCard that provides an accessible platform for creating interactive documents and applications, inspired by the original 1987 Apple software. Decker revives the spirit of HyperCard, which empowered non-programmers to build custom applications and interactive content, potentially inspiring a new generation of creative computing. Decker features 1-bit graphics and a scripting language similar to HyperTalk, and it is designed to run on modern systems while preserving the classic Macintosh look and feel.

hackernews · tosh · Jul 26, 18:23 · [Discussion](https://news.ycombinator.com/item?id=49060856)

**Background**: HyperCard was a pioneering hypermedia authoring tool released by Apple in 1987. It combined a flat-file database with a graphical interface and a built-in programming language called HyperTalk, allowing users to create interactive 'stacks' of cards. HyperCard was included free with Macs and used for everything from games to business applications, but was discontinued in 2004. Decker is a modern reimplementation that aims to bring that accessible, creative environment to contemporary computers.

The proposal parallels existing technologies like Global Privacy Control (GPC), which sends a signal via HTTP headers or browser APIs indicating the user's opt-out preference. Technologies like GPC and Do Not Track have attempted to provide browser-level opt-outs, but lacked legal teeth.

## [Claude Shared Links Indexed by Search Engines Expose Private Data](https://search.brave.com/search?q=site%3Aclaude.ai%2Fshare&amp;source=android) ⭐️ 8.0/10

A serious privacy vulnerability has been discovered in Claude's shared conversation links, where the generated public URLs are not blocked from search engine crawling, causing Google, Brave, and Bing to index sensitive user data such as API keys, crypto wallets, and personal information. This vulnerability poses an urgent privacy risk for all Claude users, as sensitive data can be easily discovered by anyone through search queries, and similar issues with ChatGPT were fixed quickly, highlighting the need for immediate action from Anthropic. The lack of a noindex meta tag or HTTP header on shared links allows search engines to index the content; Google has already blocked indexing but Brave and Bing still show results. Users are advised to manually delete sensitive shared conversations in settings.

telegram · zaihuapd · Jul 26, 11:16

**Background**: Web search engines use robots.txt and meta tags like noindex to control indexing. The noindex meta tag, when placed in a page's HTML head, instructs search engines not to include that page in search results, offering a more granular control than robots.txt. Without such measures, publicly accessible URLs can become discoverable via search.
