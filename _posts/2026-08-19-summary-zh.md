## [Turbovec：用 Rust 实现谷歌 TurboQuant 的高效向量搜索库](https://github.com/RyanCodrai/turbovec) ⭐️ 7.0/10

Turbovec 是一个基于谷歌 TurboQuant 算法的开源 Rust 向量索引库，现已发布并提供 Python 绑定。它将 1000 万个向量从 31 GB 压缩到 4 GB，并宣称在 ARM 上检索速度超过 FAISS。 Turbovec 将 TurboQuant 引入 Rust 和 Python 生态，使前沿向量压缩技术不再局限于研究原型，可在内存受限设备上实现大规模相似性检索。它也提醒人们，在 ANN 基准测试中 FAISS 已不再是默认的最优选择。 该库由 Ryan Codrai 开发并托管在 GitHub 上，针对千万级向量数据集，并特别强调 ARM 性能。社区用户表示对 SQLite 绑定充满期待，同时建议 README 写得更通俗一些以便推广采用。

hackernews · fittingopposite · Aug 18, 18:07 · [社区讨论](https://news.ycombinator.com/item?id=49349898)

**背景**: 向量量化（Vector Quantization）通过将高维嵌入压缩为更小的表示，来降低最近邻搜索所需的内存占用。TurboQuant 是 Google Research 提出、并被 ICLR 2026 收录的量化方法，具有接近最优的率失真性能，还可用于 4-bit 大语言模型量化。Turbovec 将该算法实现为独立的 Rust 向量索引，并提供 Python 绑定，便于集成到实际应用中。
