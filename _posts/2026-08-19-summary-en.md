## [Mojo Programming Language Now Open Source Under Apache 2 License](https://simonwillison.net/2026/Aug/18/mojo-is-now-open-source/) ⭐️ 9.0/10

Modular has open-sourced the Mojo programming language's compiler and toolchain under the Apache 2 license, following Mojo 1.0's release last week. The move fulfills a promise made when Mojo first launched in May 2023. This is a major milestone for the Python-adjacent language, which targets high-performance computing and AI workloads. Opening the source code could accelerate adoption and community contributions, while potentially reshaping Python ecosystem tooling. Mojo is no longer positioned as a strict superset of Python; a 2025 roadmap change allowed it to diverge from that goal. Built on the MLIR compiler framework, Mojo can target CPUs, GPUs, TPUs, and other accelerators.

rss · Simon Willison · Aug 18, 21:39

**Background**: Mojo is a systems programming language created by Modular that uses Python-like syntax but adds Rust-inspired features such as static typing and a borrow checker. It was originally intended as a superset of Python to bootstrap an ecosystem, but that plan changed around August 2025. The language uses MLIR rather than LLVM directly, enabling higher-level optimizations and support for AI hardware.

## [Long March 10B achieves world-first net-based at-sea rocket recovery](https://t.me/zaihuapd/43264) ⭐️ 8.0/10

On July 10, 2026, China's Long March 10B rocket launched from the Hainan Commercial Space Launch Site and successfully recovered its first stage at sea using a net-based catching system about six minutes after stage separation. This marks China's first controlled recovery of an orbital rocket first stage and the world's first net-based recovery of a launch vehicle. This milestone makes China the second country after the United States to successfully recover an orbital rocket booster, advancing its reusable rocket technology. The novel net-capture method could reduce launch costs and increase launch frequency, potentially reshaping the competitive landscape in commercial spaceflight. Unlike SpaceX's landing-leg approach, the Long March 10B uses a net-based catching system on a floating sea platform, which eliminates the need for landing legs and reduces the fuel required for descent. The flight validated key technologies including re-ignition, high-precision navigation and control, and the first net-based capture and recovery at sea.

telegram · zaihuapd · Aug 19, 00:16

**Background**: Reusable rocket technology is key to lowering the cost of space access. SpaceX pioneered booster recovery with propulsive landing legs, while China's Long March 10B adopts a different strategy: catching the first stage in a net on a floating platform at sea. This downrange sea recovery conserves fuel because the booster does not need to fly back to the launch site. A low-altitude demonstration flight of this approach was already conducted in China in February 2026.

## [Turbovec Brings Google's TurboQuant to Rust for Efficient Vector Search](https://github.com/RyanCodrai/turbovec) ⭐️ 7.0/10

Turbovec, an open-source Rust vector index built on Google's TurboQuant algorithm, has been released with Python bindings. It compresses 10 million vectors from 31 GB to 4 GB and reports faster search performance than FAISS on ARM. By bringing TurboQuant to Rust and Python, Turbovec makes cutting-edge vector compression accessible beyond research prototypes, enabling large-scale similarity search on memory-constrained devices. It also highlights that FAISS is no longer the automatic state-of-the-art choice for ANN benchmarks. The library is authored by Ryan Codrai and available on GitHub; it targets 10-million-vector datasets and emphasizes ARM performance. Community members note that SQLite bindings are in demand and suggest the README could be more approachable for adoption.

hackernews · fittingopposite · Aug 18, 18:07 · [Discussion](https://news.ycombinator.com/item?id=49349898)

**Background**: Vector quantization compresses high-dimensional embeddings into smaller representations to reduce the memory footprint of nearest-neighbor search. TurboQuant is a quantization method proposed by Google Research and accepted at ICLR 2026, offering near-optimal distortion-rate compression and also enabling 4-bit LLM quantization. Turbovec applies this algorithm in a standalone Rust vector index with Python bindings, making it easier to integrate into real applications.

The project demonstrates how an everyday environment can be repurposed as an imaging device, offering a fresh perspective on both photography and train travel. It has already inspired community members to share their own slit-scan experiments and tools, showing its resonance with creative coders and photographers. The technique involves capturing a thin vertical slice of pixels over time as the train moves, producing the scan effect. Commenters note that the unexpected 'error' shots are often more captivating than the planned ones, and one user shared a similar manual frame-splicing technique with 15-pixel-wide lines.

**Background**: Slit-scan photography is a technique where a slit is placed between the camera and the moving subject during a long exposure, resulting in stretched or abstracted images. It was historically used to create 'finish photos' in races, showing a slice of the finish line over time. In this project, the train's own motion provides the scan, replacing a mechanical slit with the window frame.
