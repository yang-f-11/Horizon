This closes a latent attack vector that could have allowed attackers to poison long-stable releases, protecting millions of Python users from potential malicious code injection. The restriction applies to all packages on PyPI, and as of the announcement, no known abuse of this vector has occurred. The change was made via a pull request on the Warehouse repository.

**Background**: PyPI (Python Package Index) is the official third-party software repository for the Python programming language.
