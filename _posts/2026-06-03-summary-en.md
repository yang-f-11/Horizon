## [Microsoft Unveils Efficient MAI Models with Low Active Parameters](https://simonwillison.net/2026/Jun/2/microsofts-new-models/#atom-everything) ⭐️ 8.0/10

Microsoft announced two new large language models: MAI-Thinking-1, a 1 trillion parameter reasoning model with 35 billion active parameters, and MAI-Code-1-Flash, a 137 billion parameter code model with 5 billion active parameters, both using Mixture-of-Experts architecture. These models demonstrate significant efficiency gains, as they achieve competitive performance with much larger dense models while using far fewer active parameters, potentially lowering inference costs and enabling deployment on more modest hardware. MAI-Thinking-1 is claimed to be preferred over Claude Sonnet 4.6 in blind evaluations, though the model's training data still relies on web crawls with licensing concerns, similar to other major LLMs.

rss · Simon Willison · Jun 2, 22:21

**Background**: Large language models often use Mixture-of-Experts (MoE) architecture, where only a subset of parameters (active parameters) are used for each input, reducing computational cost. The total parameter count includes all experts, but active count determines inference cost. Microsoft's new models have very low active parameter ratios (e.g., 5B active out of 137B total), making them more efficient than dense models of similar total size.
